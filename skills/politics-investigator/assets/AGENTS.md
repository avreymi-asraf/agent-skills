# Research Project (`AGENTS.md`)

This repository holds living primary-source dossiers on politics and public affairs under `research-vault/`. Use the `politics-investigator` skill for `open`, `update`, and `refactor` workflows.

## Structure

- `research-vault/INDEX.md`: map of active affairs, statuses, thesis summaries, and global priorities.
- `research-vault/affairs/<slug>/brief.md`: living synthesis, governing thesis, stakeholder matrix, evidence ledger, and queue.
- `research-vault/affairs/<slug>/raw-sources.md`: full verbatim source extracts and visual artifact logs.
- `research-vault/affairs/<slug>/assets/`: downloaded documents, charts, maps, and screenshots.

## Rules

- Read `research-vault/INDEX.md` and `research-vault/affairs/<slug>/brief.md` before updating; read `raw-sources.md` when verifying citations.
- Treat X/social posts, press summaries, and leaks as leads, never proof—reconcile with Tier 1 primary records and keep URLs + capture dates.
- Rewrite analytical prose in `brief.md` in place; never append dated news bullets.
- **Git:** work directly on `main`, commit changes cleanly, and push immediately (`git push`).
